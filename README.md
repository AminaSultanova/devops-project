# DevOps Infrastructure Repository

## Project Description
This repository contains core DevOps infrastructure setups including IaC, containerization, orchestration, and monitoring.

## Structure
- **terraform/** - Infrastructure as Code (IaC)
- **ansible/** - Playbooks & Automation
- **docker/** - Dockerfile & Environment
- **kubernetes/** - Deployment & Service manifests
- **monitoring/** - Prometheus configuration
- **scripts/** - Helper scripts
- **.github/workflows/** - CI/CD Pipeline
